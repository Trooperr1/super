# سیستەمی POS بۆ سوپەرمارکێت

سیستەمێکی تەواوی خاڵی فرۆشتن (Point of Sale) بە .NET 8 WPF دروستکراوە بۆ سوپەرمارکێتەکان، لەگەڵ پشتگیری تەواوی زمانی کوردی و ڕێکخستنی ڕاست-بۆ-چەپ (RTL).

## دەستپێکردن 🚀

### پێداویستییەکان

پێش کارپێکردنی بەرنامەکە، دڵنیابە لە هەبوونی:

1. **.NET 8 SDK** - [دابەزاندن](https://dotnet.microsoft.com/download/dotnet/8.0)
2. **SQL Server** (LocalDB، Express، یان Full) - [دابەزاندن](https://www.microsoft.com/sql-server/sql-server-downloads)
3. **Visual Studio 2022** یان **Visual Studio Code** (دڵخواز بەڵام پێشنیارکراو)
4. **Windows 10/11** - پێویستە بۆ بەرنامەکانی WPF

### هەنگاوەکانی دامەزراندن

#### ١. دابەزاندن یان کۆپیکردنی پرۆژەکە

```bash
git clone <repository-url>
cd SupermarketPOS
```

#### ٢. ڕێکخستنی گرێدان بە بنکەی دراوە

کردنەوەی `SupermarketPOS.WPF/appsettings.json` و نوێکردنەوەی ستڕینگی گرێدان:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=SupermarketPOS;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true"
  }
}
```

**هەڵبژاردەکانی ستڕینگی گرێدان:**

بۆ SQL Server Express:
```
Server=localhost\\SQLEXPRESS;Database=SupermarketPOS;Trusted_Connection=True;TrustServerCertificate=True
```

بۆ SQL Server لەگەڵ یوزەر و پاسوۆرد:
```
Server=localhost;Database=SupermarketPOS;User Id=ناوی_بەکارهێنەر;Password=وشەی_نهێنی;TrustServerCertificate=True
```

#### ٣. گەڕاندنەوەی پاکێجەکانی NuGet

```bash
dotnet restore
```

#### ٤. دروستکردنی مایگرەیشنی بنکەی دراوە

```bash
cd SupermarketPOS.Infrastructure
dotnet ef migrations add InitialCreate --startup-project ../SupermarketPOS.WPF
```

#### ٥. نوێکردنەوەی بنکەی دراوە

```bash
dotnet ef database update --startup-project ../SupermarketPOS.WPF
```

**تێبینی:** بەرنامەکە بە شێوەیەکی ئۆتۆماتیکی بنکەی دراوە دەخوێنێتەوە و داتای سەرەتایی دەچێنێت لە یەکەم جار.

#### ٦. بیلدکردنی سۆڵیوشن

```bash
cd ..
dotnet build
```

#### ٧. کارپێکردنی بەرنامەکە

```bash
cd SupermarketPOS.WPF
dotnet run
```

یان کردنەوەی سۆڵیوشنەکە لە Visual Studio و دەستی نان لە F5.

## شێمای بنکەی دراوە 🗄️

### خشتە سەرەکییەکان

- **Products (بەرهەمەکان)** - زانیاری بەرهەم لەگەڵ بارکۆد، نرخ، مەخزەن
- **Categories (پۆلێنەکان)** - پۆلێنەکانی بەرهەم
- **Suppliers (دابینکەران)** - زانیاری دابینکەران
- **Customers (کڕیارەکان)** - داتای کڕیار لەگەڵ خاڵی دڵسۆزی
- **Users (بەکارهێنەران)** - بەکارهێنەرانی سیستەم لەگەڵ ڕۆڵەکان
- **Sales (فرۆشتنەکان)** - مامەڵەکانی فرۆشتن
- **SaleItems (بڕگەکانی فرۆشتن)** - بەرهەمە تاکەکانییەکان لە هەر فرۆشتنێکدا
- **InventoryTransactions (مامەڵەکانی مەخزەن)** - مێژووی جوڵەی مەخزەن
- **UserActivityLogs (لۆگی چالاکی)** - شوێنپێی چاودێری

## دڵخوازکردن 🎨

### گۆڕینی زانیاری کۆمپانیا

دەستکاری کردنی `appsettings.json`:

```json
{
  "AppSettings": {
    "CompanyName": "ناوی کۆمپانیاکەت",
    "Address": "ناونیشانی کۆمپانیاکەت",
    "Phone": "07501234567",
    "TaxRate": 5.0,
    "Currency": "IQD",
    "ReceiptFooter": "سوپاس بۆ کڕینەکەت"
  }
}
```

### دڵخوازکردنی ڕووکار

بەرنامەکە ڕووکارەکانی MaterialDesign بەکاردێنێت. بۆ گۆڕینی ڕەنگەکان، دەستکاری کردنی `App.xaml`:

```xml
<materialDesign:BundledTheme BaseTheme="Light"
                           PrimaryColor="DeepPurple"
                           SecondaryColor="Lime" />
```

ڕەنگە بەردەستەکان: Red, Pink, Purple, DeepPurple, Indigo, Blue, LightBlue, Cyan, Teal, Green, LightGreen, Lime, Yellow, Amber, Orange, DeepOrange, Brown, Grey, BlueGrey

## چارەسەرکردنی کێشەکان 🔧

### کێشەکانی گرێدان بە بنکەی دراوە

**کێشە:** ناتوانێت گرێبدات بە SQL Server

**چارەسەرەکان:**
1. دڵنیابە SQL Server کاردەکات
2. پشکنینی ستڕینگی گرێدان لە appsettings.json
3. بۆ SQL Express، بەکاربێنە: `Server=localhost\\SQLEXPRESS`
4. چالاککردنی TCP/IP لە SQL Server Configuration Manager

### هەڵەکانی مایگرەیشن

ئەگەر هەڵەی مایگرەیشن وەربگریت، تاقیبکەرەوە:

```bash
# سڕینەوەی فۆڵدەری migrations
cd SupermarketPOS.Infrastructure
rm -rf Migrations

# دروستکردنی مایگرەیشنی نوێ
dotnet ef migrations add InitialCreate --startup-project ../SupermarketPOS.WPF

# نوێکردنەوەی بنکەی دراوە
dotnet ef database update --startup-project ../SupermarketPOS.WPF
```

### کێشەکانی نیشاندانی دەقی کوردی

ئەگەر دەقی کوردی شکاو دەردەکەوێت:
1. دڵنیابە Windows پاکێجی زمانی کوردی داگرتووە
2. فۆنتەکانی بەکاربێنە: Segoe UI، Calibri، یان Arial
3. پشکنین بکە FlowDirection دانراوە بۆ RightToLeft لە XAML
